# Machine Learning Basics
We can classify ML into four categories. supervised, unsupervised, reinforcement learning and Gen AI.

## Supervised
Model learns from the labelled example data provided and apply the learning on new input.
Can be further classified based on output it produces into

1. Regression : Output is a continuous number. eg: house price prediction, mark prediction etc.
2. Binary classification : Output is yes/no. eg: email is spam or not, is there a cat in the picture etc.
3. Multiclass classification: Output predicts different classes . eg: Climate tomorrow, (rain, sunny, partially sunny ...)

## Unsupervised
Instead of training the model without a labelled training data. Model basically learns to create clusters based on the similarity of the data.
eg: A model distinguishing fruits and flowers 

## Gen AI
Generates new input similar to the data the model learns. 
it can be text to text (chatbots) , text (+image/sound/video) to text (+image/sound/video) etc models.
eg: LLMS
